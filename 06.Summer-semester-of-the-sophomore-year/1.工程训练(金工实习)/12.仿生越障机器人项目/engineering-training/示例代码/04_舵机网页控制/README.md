# 04 舵机网页控制

## 本例程学什么

本例程让 ESP32-S3 建立一个 Wi-Fi 热点，并提供一个简单网页。手机或电脑连接热点后，可以通过网页按钮控制单个 PWM 舵机。

完成后，你应该能理解：

1. ESP32-S3 的 AP 模式，即开发板自己发出 Wi-Fi 热点。
2. 浏览器如何通过 HTTP 请求控制开发板。
3. 舵机为什么必须使用独立 5V 电源。
4. 用 `millis()` 实现非阻塞舵机转动，避免网页请求卡住。

---

## 硬件接线

### 舵机供电

舵机不要直接从 ESP32 的 3.3V 或 5V 引脚取电。舵机启动和受力时电流较大，直接从开发板取电容易造成 ESP32 复位、USB 口过流或舵机抖动。

推荐使用独立 5V 电源，例如 5V/1A 以上的稳压电源、USB 充电器或移动电源。舵机电源负极必须和 ESP32 GND 相连。

| 舵机线 | 连接到 | 说明 |
|--------|--------|------|
| 红线 | 外部 5V 电源正极 | 舵机供电 |
| 棕/黑线 | 外部 5V 电源负极 | 舵机 GND |
| 黄/橙/白线 | ESP32 GPIO13 | PWM 信号 |
| ESP32 GND | 外部 5V 电源负极 | 共地 |

接线示意：

```text
外部 5V+  -> 舵机红线
外部 5V-  -> 舵机棕/黑线
ESP32 GND -> 外部 5V-
GPIO13    -> 舵机黄/橙/白信号线
```

## 使用步骤

### 1. 上传代码

1. 打开 `04_servo_web_control.ino`。
2. 选择正确的 ESP32-S3 板卡和端口。
3. 上传程序。
4. 打开串口监视器，波特率选择 `115200`。

### 2. 连接热点

上传后，ESP32-S3 会建立 Wi-Fi 热点：

```text
SSID: ESP32S3_SERVO
Password: 12345678
```

手机或电脑连接这个热点。连接后如果系统提示“无互联网连接”，这是正常现象，因为这个热点只用于访问 ESP32。

### 3. 打开网页

浏览器访问：

```text
http://192.168.4.1
```

网页上有三个按钮：

| 按钮 | 作用 |
|------|------|
| 左 45° | 舵机转到 45° |
| 回中 90° | 舵机转到 90° |
| 右 135° | 舵机转到 135° |

---

## 预期现象

串口监视器会显示：

```text
Wi-Fi AP started
SSID: ESP32S3_SERVO
IP: 192.168.4.1
```

点击网页按钮后，串口会输出目标角度：

```text
targetAngle = 45
targetAngle = 90
targetAngle = 135
```

舵机会以每 15 毫秒约 1 度的速度转向目标角度。网页请求会立即返回，舵机转动过程不会阻塞网页。

---

## 代码要点

### AP 模式

```cpp
WiFi.softAP(ssid, password);
```

这行代码让 ESP32-S3 建立热点。默认情况下，AP 模式的访问地址通常是 `192.168.4.1`。

### 网页路由

```cpp
server.on("/", []() {
  server.send(200, "text/html", htmlPage());
});
```

访问根路径 `/` 时，ESP32 返回控制网页。

```cpp
server.on("/servo", []() {
  if (server.hasArg("angle")) {
    targetAngle = constrain(server.arg("angle").toInt(), 0, 180);
  }
  server.send(200, "text/plain", "OK");
});
```

访问 `/servo?angle=90` 时，ESP32 读取 `angle` 参数并更新目标角度。

### 非阻塞更新

舵机没有在网页请求函数中直接转到目标角度，而是在 `loop()` 中逐步更新：

```cpp
void loop() {
  server.handleClient();
  updateServo();
}
```

这样做的好处是：网页请求处理很快，舵机转动也能持续进行。

## 常见问题

### 找不到 `ESP32S3_SERVO` 热点

1. 确认程序已成功上传。
2. 打开串口监视器，看是否出现 `Wi-Fi AP started`。
3. 按 EN 或 RST 复位开发板。
4. 如果串口反复输出重启信息，优先检查供电。

### 浏览器打不开 `192.168.4.1`

1. 确认手机或电脑已经连接 `ESP32S3_SERVO`。
2. 关闭手机移动数据或“自动切换网络”功能。
3. 地址栏输入 `http://192.168.4.1`。
4. 重新刷新页面或换一个浏览器。

### 舵机不动或抖动

1. 舵机红线必须接外部 5V 电源正极。
2. 舵机电源负极必须和 ESP32 GND 共地。
3. 信号线应接到 GPIO13。
4. 如果舵机仍然抖动，换更大电流的 5V 电源，并检查机械负载。

### 点击按钮没有反应

1. 打开串口监视器，看点击按钮后是否输出 `targetAngle = ...`。
2. 如果串口有输出但舵机不动，重点查接线和供电。
3. 如果串口没有输出，刷新网页或检查手机是否仍连接 ESP32 热点。
