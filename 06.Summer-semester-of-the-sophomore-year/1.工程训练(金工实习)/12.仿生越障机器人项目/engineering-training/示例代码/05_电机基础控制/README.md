# MG4010-i10 RS485 基础控制

## 功能说明

通过 ESP32-S3、课程配套 RS485/供电转接板或通用 RS485 模块，以及厂家私有 RS485 协议控制 MG4010-i10 电机，实现使能、停止、关闭、清除错误、读取状态和读取多圈角度。

本例程的重点是**确认 RS485 通信已经跑通**，不是让电机持续转动。代码中没有发送速度命令或位置命令，所以输入 `r` 后电机通常不会自己转起来。

注意：本电机的厂家协议不是 Modbus-RTU。示例代码使用帧头 `0x3E`、命令字和校验和。

## 硬件需求

1. ESP32-S3 开发板
2. MG4010-i10 电机（RS485 版本）
3. RS485/供电转接板（推荐）或 3.3V 兼容 RS485 转换模块
4. 12V~24V 直流电源，首次测试建议使用 24V 2A 以上
5. 杜邦线

## 接线

推荐优先使用课程配套 RS485/供电转接板。按板子丝印连接：

| ESP32-S3 | 转接板 | 说明 |
|----------|--------|------|
| 5V | USB调试 5V | 转接板逻辑供电 |
| GND | USB调试 G | 共地 |
| GPIO17 (TX) | TTL-485 调试 T | 发送数据，TX 接 T |
| GPIO18 (RX) | TTL-485 调试 R | 接收数据，RX 接 R |

| 电机/电源 | 转接板 |
|----------|--------|
| 24V 电源正极 | 输入端子上孔 |
| 24V 电源负极 | 输入端子下孔 |
| MG4010 B/L | 电机 6pin 第 1 pin：B |
| MG4010 A/H | 电机 6pin 第 2 pin：A |
| MG4010 V- | 电机 6pin 第 3、4 pin：GND |
| MG4010 V+ | 电机 6pin 第 5、6 pin：24V |

如果不用转接板，再按下面的通用 RS485 模块接线：

| ESP32-S3 | RS485 模块 | 说明 |
|----------|------------|------|
| GPIO17 | DI | 发送数据 |
| GPIO18 | RO | 接收数据 |
| GPIO16 | DE + RE | 收发方向控制 |
| 3.3V | VCC | 模块供电 |
| GND | GND | 共地 |

课程配套转接板已在板上处理 RS485 收发方向，ESP32 不需要接 GPIO16。只有使用通用 RS485 模块时，才需要 GPIO16 控制 DE/RE。接线前仍要看清开发板丝印，不要把信号线误接到 3.3V、5V 或 GND。

| RS485 模块 | MG4010-i10 |
|------------|------------|
| A | A/H |
| B | B/L |

电机电源：

- V+ 接电源正极
- V- 接电源负极
- ESP32 GND、RS485/供电转接板或 RS485 模块 GND、电机 V- 必须共地

## 协议参数

```text
波特率：115200
数据格式：8N1
默认 ID：1
帧头：0x3E
```

## 串口命令

打开串口监视器，波特率选择 115200。

| 命令 | 功能 |
|------|------|
| `r` | 电机使能，进入可控制状态（不等于开始转动） |
| `t` | 电机停止 |
| `o` | 电机关闭 |
| `c` | 清除错误 |
| `s` | 读取状态 2 |
| `a` | 读取多圈角度 |
| `z` | 设置当前位置为零点，写入 ROM，谨慎使用 |
| `h` | 显示帮助 |

## 使用步骤

1. 断电状态下完成接线。
2. 确认电源正负极、A/B、共地无误。
3. 上传程序，打开串口监视器。
4. 给电机上电。
5. 先输入 `s` 读取状态，再输入 `r` 让驱动器进入可控制状态。这一步不会让输出轴自己转动。
6. 需要停止时输入 `t`。

## 为什么输入 `r` 后电机不转

MG4010-i10 的厂家协议把“运行状态”和“运动目标”分成了不同命令：

| 动作 | 命令字 | 作用 |
|------|--------|------|
| 使能 / 运行状态 | `0x88` | 让电机从关闭状态进入可控制状态 |
| 停止 | `0x81` | 停止当前运动 |
| 速度闭环 | `0xA2` | 给电机一个目标速度，电机才会按速度转动 |
| 位置闭环 | `0xA4` | 给电机一个目标角度和速度限制，电机才会转到目标位置 |

本例程只发送 `0x88`、`0x81`、`0x9C`、`0x92` 等基础命令，用来验证：

1. ESP32 能把 RS485 命令发出去。
2. 电机能按 ID 回复。
3. 帧头、校验和、波特率、A/B、TX/RX、共地都正确。
4. 串口能读到温度、转速、编码器和多圈角度。

因此，在 `05_电机基础控制` 中看到“电机已进入可控制状态”，含义是**驱动器已经使能**，不是“输出轴正在转动”。

## 想让电机真正转动怎么办

确认 `05_电机基础控制` 能读到状态后，再进入下一个例程：

```text
示例代码/06_电机速度模式/06_motor_speed_mode.ino
```

`06_电机速度模式` 会发送速度闭环命令 `0xA2`。串口中输入的是**输出轴 RPM**，例如：

| 输入 | 现象 |
|------|------|
| `5` | 输出轴低速正转，约 5 RPM |
| `10` | 输出轴正转，约 10 RPM |
| `-10` | 输出轴反转，约 10 RPM |
| `t` | 停止电机 |
| `s` | 读取状态 |

第一次让电机转动时建议：

1. 电机空载，不要装到机构上。
2. 先输入 `5`，确认方向和供电正常。
3. 再尝试 `10` 或 `-10`。
4. 出现发热、异响、复位、失控时立即断电。

学习顺序不要跳过 `05`。如果 `05` 不能稳定读状态，直接运行 `06` 也大概率无法控制电机转动。
