# 09 机器人整合控制

## 功能说明

本例程把两个 MG4010-i10 RS485 电机和四个 PWM 舵机接到同一块 ESP32-S3 上，通过串口命令进行控制。

适合在完成以下例程后再学习：

- `03_舵机基础控制`
- `05_电机基础控制`
- `06_电机速度模式`
- `07_电机位置模式`

本例程重点不是新增某一种硬件，而是学习如何把多个模块放进同一个主循环中，并保持串口命令、RS485 通信和舵机 PWM 更新互不干扰。

---

## 硬件需求

| 硬件 | 说明 |
|------|------|
| ESP32-S3 开发板 | 主控制器 |
| MG4010-i10 RS485 电机 2 个 | 左右轮，ID 分别设为 1 和 2 |
| RS485/供电转接板 | 推荐使用课程配套转接板 |
| 12V~24V 电机电源 | 给电机供电，首次测试建议 24V |
| PWM 舵机 4 个 | 接 GPIO10、11、12、13 |
| 独立 5V 舵机电源 | 建议 3A 以上，视舵机型号和负载调整 |

---

## 接线

### RS485 电机

| ESP32-S3 | 转接板接口 | 说明 |
|----------|------------|------|
| GPIO17 | TTL-485 调试口 T | ESP32 发送 |
| GPIO18 | TTL-485 调试口 R | ESP32 接收 |
| GND | 转接板 GND | 共地 |

两个电机接在同一条 RS485 A/B 总线上，但 ID 必须不同：

```text
左电机 ID = 1
右电机 ID = 2
```

如果两个电机 ID 相同，它们会同时响应命令，读取状态时还可能造成总线冲突。

### 舵机

| 舵机 | ESP32-S3 信号引脚 | 供电 |
|------|-------------------|------|
| 舵机 1 | GPIO10 | 外部 5V |
| 舵机 2 | GPIO11 | 外部 5V |
| 舵机 3 | GPIO12 | 外部 5V |
| 舵机 4 | GPIO13 | 外部 5V |

舵机红线接外部 5V 正极，棕/黑线接外部 5V 负极，信号线接表中 GPIO。舵机电源负极必须和 ESP32 GND 相连。

### 共地

最终系统必须形成公共地：

```text
ESP32 GND
RS485/供电转接板 GND
电机电源负极
舵机电源负极
```

不要用 ESP32 的 3.3V 或 5V 引脚给舵机、电机供电。上电前先断电检查电源正负极、A/B 和 GND。

## 使用步骤

1. 先分别运行舵机和电机单模块例程，确认硬件能单独工作。
2. 给两个 MG4010-i10 电机设置不同 ID，建议左电机为 1，右电机为 2。
3. 上传 `09_robot_integrated_control.ino`。
4. 打开串口监视器，波特率选择 `115200`，行尾选择“换行”或 `Both NL & CR`。
5. 先空载低速测试，再安装到机器人结构上。

## 串口命令

| 命令 | 作用 |
|------|------|
| `v 20 20` | 左右电机都以 20 RPM 转动 |
| `v -20 -20` | 左右电机反向转动 |
| `v 20 -20` | 左右电机反向，适合原地转向测试 |
| `pose 90 90 90 90` | 四个舵机都转到 90° |
| `pose 45 90 135 0` | 四个舵机分别转到指定角度 |
| `home` | 电机停止，四个舵机回到 90° |
| `stop` | 停止两个电机，舵机保持当前目标 |

首次测试建议从 `v 10 10` 或 `v 20 20` 开始，不要直接使用高速度。

---

## 预期现象

启动后串口会显示安全检查提示和可用命令。舵机会初始化到 90° 中位，电机等待命令。

输入：

```text
v 20 20
```

串口输出类似：

```text
收到命令: v 20 20
设置速度：左 20.0 RPM，右 20.0 RPM
```

输入：

```text
pose 45 90 135 0
```

串口输出类似：

```text
收到命令: pose 45 90 135 0
设置舵机角度：45° 90° 135° 0°
```

## 代码要点

### 1. 同一条 RS485 总线控制两个电机

两个电机共用 GPIO17/GPIO18 和 RS485 A/B 总线。程序发送命令时把电机 ID 写入协议帧：

```cpp
sendMotorCommand(MOTOR_ID_LEFT, CMD_SPEED_MODE, params, 4);
sendMotorCommand(MOTOR_ID_RIGHT, CMD_SPEED_MODE, params, 4);
```

电机只处理和自己 ID 匹配的命令。

### 2. 速度单位换算

用户输入的是输出轴 RPM，协议需要电机侧 `0.01 dps`：

```text
输出轴 RPM -> 输出轴 dps -> 电机侧 dps -> 协议值
```

MG4010-i10 减速比为 1:10，因此：

```text
协议值 = 输出轴 RPM × 6 × 10 × 100
```

### 3. 舵机非阻塞更新

`loop()` 中持续调用：

```cpp
processCommand();
updateServos();
```

`updateServos()` 使用 `millis()` 定时刷新 PWM，不在主循环中长时间 `delay()`。这样串口命令仍能及时处理。

## 常见问题

### 电机没有反应

1. 先用 `05_电机基础控制` 单独测试一个电机。
2. 确认电机有独立 12V~24V 电源。
3. 确认 ESP32、转接板、电机电源负极共地。
4. 对调 A/B 线测试。
5. 确认左电机 ID 为 1，右电机 ID 为 2。

### 舵机抖动或转不到位

1. 舵机必须使用独立 5V 电源。
2. 舵机电源负极必须和 ESP32 GND 共地。
3. 电源电流不足时，换更大电流的 5V 电源。
4. 拆掉机械负载，先测试舵机本体。

### 串口输入命令无响应

1. 串口监视器波特率选择 `115200`。
2. 行尾选择“换行”或 `Both NL & CR`。
3. 命令中参数用空格分隔，例如 `v 20 20`。
4. 上传后按 EN 或 RST 复位开发板。

### 电机和舵机一起工作时异常

如果单独测试都正常，合并后异常，优先检查供电和地线布局。舵机动作时电流变化较大，可能导致 ESP32 复位或 RS485 通信不稳定。
