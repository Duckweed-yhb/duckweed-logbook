# 03 舵机基础控制

## 本例程学什么

本例程通过串口输入角度，控制一个 PWM 舵机转动。它是本教程第一次外接执行器的实验，重点是接线、独立供电、共地和串口命令输入。

完成后，你应该能做到：

1. 正确连接一个 PWM 舵机。
2. 使用外部 5V 电源给舵机供电。
3. 在串口监视器输入角度，让舵机转到目标位置。
4. 判断舵机不动、抖动、ESP32 复位时应先检查什么。

---

## 硬件

| 硬件 | 说明 |
|------|------|
| ESP32-S3 开发板 | 主控制器 |
| PWM 舵机 1 个 | SG90、MG90S 或类似舵机均可 |
| 独立 5V 电源 | 建议 5V/1A 以上 |
| 杜邦线 | 连接信号线、电源和 GND |

---

## 接线

舵机必须使用独立 5V 电源。不要把舵机红线接到 ESP32 的 3.3V 引脚。

```text
舵机红线       -> 外部 5V+
舵机棕/黑线    -> 外部 5V-
ESP32 GND      -> 外部 5V-（共地）
舵机黄/橙/白线 -> ESP32 GPIO13
```

共地很重要。ESP32 的 GND 和舵机电源负极不连接时，舵机可能完全不动或动作异常。

## 使用步骤

### 1. 上传代码

1. 打开 `03_servo_basic.ino`。
2. 选择正确的 ESP32-S3 板卡和端口。
3. 上传程序。
4. 打开串口监视器，波特率选择 `115200`。
5. 串口监视器行尾建议选择“换行”或 `Both NL & CR`。

### 2. 输入角度

在串口监视器输入框中输入 0 到 180 之间的数字，然后按回车。

常用测试值：

| 输入 | 预期现象 |
|------|----------|
| `90` | 舵机转到中位 |
| `45` | 舵机向一侧转动 |
| `135` | 舵机向另一侧转动 |
| `0` | 舵机转到一端 |
| `180` | 舵机转到另一端 |

首次测试建议从 `90` 开始，再测试 `45` 和 `135`。不要一开始就反复在 `0` 和 `180` 之间切换，避免机械结构卡住。

---

## 预期串口输出

启动后会看到：

```text
ESP32-S3 基础舵机控制
请输入角度（0-180）并按回车：
舵机初始化完成，当前角度: 90°
```

输入 `45` 后，会看到类似输出：

```text
目标角度设置为: 45°
当前角度: 89
当前角度: 88
...
当前角度: 45
```

程序每次只移动 1°，因此舵机是逐步转动到目标角度，不是瞬间跳过去。

## 代码要点

### 角度范围限制

```cpp
targetAngle = constrain(inputAngle, 0, 180);
```

这行代码把输入限制在 0° 到 180°，避免输入过大或过小导致异常。

### 角度转 PWM

```cpp
int pulseUs = map(angle, 0, 180, minUs, maxUs);
```

舵机接收的是 PWM 脉宽，不是角度数字。程序把 0° 到 180° 映射到 500us 到 2500us 的脉宽范围。

### 非阻塞平滑转动

```cpp
if (now - lastServoUpdate < servoInterval) return;
```

程序用 `millis()` 判断是否到了更新时间，到了才让舵机移动 1°。这种写法不会长时间卡住主循环，后面做网页控制和多舵机控制时也会用到。

## 常见问题

### 舵机不动

1. 检查信号线是否接到 GPIO13。
2. 检查舵机红线是否接外部 5V。
3. 检查 ESP32 GND 是否和舵机电源负极共地。
4. 确认串口输入的是数字，并且按了回车。

### 舵机抖动

1. 优先检查 5V 电源电流是否足够。
2. 舵机电源线尽量短，不要经过接触不良的面包板。
3. 拆掉机械负载，只测试舵机本体。
4. 必要时在舵机电源附近并联 100μF-1000μF 电解电容（抖动严重时用 470μF 以上）。

### ESP32 复位或串口断开

通常是舵机供电影响到了 ESP32。确认舵机没有从 ESP32 取电，并使用独立 5V 电源。

### 角度方向和预期相反

不同舵机安装方向不同。先接受“输入不同角度会转到不同位置”，装到结构上以后再根据机械方向调整代码或安装方向。
