## 📊 综合评分体系总览
课程综合评分由**工程素养、工程技能、工程综合、工程认知、工程创新**5个维度构成，全方位考核团队表现。

| 评价维度 | 考核项目 | 评分细则 |
| ---- | ---- | ---- |
| **工程素养** | 考勤 | 满分100分；缺课一次扣10分，迟到或早退一次扣3分，扣分持续累加直至分数扣完。 |
| | 物料回收 | 满分100分；缺失1件物料扣10分，扣完为止。 |
| **工程技能** | 项目完成节点 | 每次课节点按时提交资料得100分；延迟提交50分，不提交0分。 |
| **工程综合** | 对抗赛成绩 | 满分100分，严格按照竞速竞技规则执行打分。 |
| **工程认知** | 项目答辩 | 满分100分，由各位评审老师打分，取总分平均值。 |
| **工程创新** | 专利三性 | 满分100分；依据答辩展示的创新点进行打分。 |

## 可选拓展选修模块（8学时自主任选其一）
1. **仿人形机器人基础实践**
    - 课程容纳人数：14人
    - 课程内容：仿人机器人概述；开发环境配置；aelos edu软件操作；编写代码实现指定动作；OpenCV视觉识别基础；完成目标跟随并执行动作。
2. **空地协同系统应用与实践**
    - 最多容纳人数：12人
    - 课程内容：SDK控制无人机与移动机器人运动；火灾点目标识别；光学动作捕捉系统使用；无人机与移动机器人空地协同灭火。
3. **微型固定翼的制作与试飞**
    - 最多容纳人数：8人（2人/组）
    - 课程内容：学习固定翼飞行器稳定性与操纵性原理；航空模型入门制作；外场试飞；结合飞行表现深化理论理解。
    - 备注：受深圳市空域飞行管控政策约束，本模块实训安排在周六、周日开展。
4. **视觉应用软件开发技术实践**
    - 最多容纳人数：10人
    - 课程内容：视觉质检基础流程；MVTec HALCON算子学习；基于视觉实现质检自动化；视觉应用软件开发实践。
