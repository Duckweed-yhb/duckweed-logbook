# 产品设计——先进数字化制造实训模块设计要求
### 1. 逆向工程与3D打印
- 实践内容：操作桌面FDM 3D打印机完成作品打印
- 设备参数：成型尺寸220×220×200mm；耗材PLA
- 提交与设计约束：
  1. 输出**STL格式三维模型**；
  2. 打印时长控制在2小时以内，模型体量不宜过大；
  3. 禁止表面复杂精细造型（手办、动漫人物等难以稳定成型）。

### 2. 激光加工
- 实践项目：**校庆主题木质拼图**
- 设备：非金属激光切割机（500×500mm）、激光打标机（150×150mm）
- 耗材：3mm椴木板
- 提交与工艺约束：
  1. 输出**DXF二维图纸**；
  2. 基础板材规格200×200mm，优秀方案可申请额外耗材；
  3. 重点配合公差要求：板材厚度3mm，配合孔建议设计2.5mm，实现紧配插接。

### 3. 钣金加工工艺
#### 钣金作品设计硬性要求
- 材料：1mm镀锌钢板
1. 输出**DXF（2007版本最优）二维图纸**；
2. 基础外形尺寸上限200×300mm，优秀方案可申请更大耗材。
#### 详细工艺设计规范
##### 激光切割图纸规范
1. 图形距离板材边框最小距离≥10mm；
2. 图形内部线条间距≥2mm；
3. 最小孔径≥板材厚度（1mm）。
##### 折弯图纸与结构规范
1. 图纸中折弯线使用虚线绘制；
2. 最小折弯高度不小于15mm；
3. 结构设计必须预留间隙，避免折弯成型后零件相互干涉碰撞。

### 4. 电火花线切割
- 绘图与图纸硬性要求：
1. 使用AutoCAD绘制，输出**2007版DXF格式文件**；
2. 轮廓必须为**无交叉、无断线闭合一笔画图形**；
3. 零件外框尺寸限定30mm×30mm；
4. 禁止重复线条、相交线条，禁用样条曲线，线条简洁规整。
