# 视觉应用软件开发技术实践
> 小班实训，最多容纳10人

## 课程简介
本实训围绕工业视觉质检场景开展实战训练，以 MVTec HALCON 工具为核心，循序渐进完成从视觉基础流程到完整视觉应用软件的开发训练，侧重工程实操能力培养。

## 实验设备与软件
- **硬件**：机器视觉实验教学平台（含工业相机）
- **软件**：
  - MVTec HALCON 开发库
  - Visual Studio 2022（C++）

## 课程内容

### 实验任务1：Blob分析实现PCB焊片缺陷检测
基于 HALCON 平台，使用 Blob（Binary Large Object）分析方法，实现对 PCB 电路板焊片区域的提取与缺陷检测。

**主要流程：**

1. **图像采集与预处理**
   - 连接工业相机拍摄焊板图片，要求清晰、焊板相对于工作台放正
   - 使用 `read_image` 算子加载图像
   - 图像灰度化（`rgb3_to_gray`），转换为单通道灰度图便于后续处理

2. **ROI 区域提取**
   - 手动绘制矩形选择待检测的焊片区域（`draw_rectangle1`）
   - 生成 ROI 并裁剪子图像（`gen_rectangle1` → `reduce_domain`）

3. **阈值分割**
   - 借助灰度直方图工具确定合适的分割阈值区间
   - 使用 `threshold` 算子提取目标区域

4. **数学形态学处理**
   - 圆形结构元素开运算（`opening_circle`），去除孤立噪点和干扰
   - 断开连通域（`connection`）

5. **特征筛选与形状分析**
   - 利用特征直方图，按面积特征筛选目标区域（`select_shape`）
   - 区域转矩形（`shape_trans`），计算最小外接矩形（`smallest_rectangle2`）
   - 获取每个焊片的中心坐标、倾斜角、长宽信息

6. **缺陷判定**
   - **数量检测**：焊片区域总数应为 **10个**（10个LED贴片），少于10个判定为漏焊/缺焊
   - **倾斜检测**：任一焊片倾斜角（弧度）大于 0.08 判定为倾斜过大、不合格
   - 对缺陷区域用红色标注，合格区域用绿色标注

**涉及的 HALCON 核心算子：**
`read_image`、`rgb3_to_gray`、`draw_rectangle1`、`gen_rectangle1`、`reduce_domain`、`threshold`、`opening_circle`、`connection`、`select_shape`、`shape_trans`、`smallest_rectangle2`、`count_obj`、`sort_region`


### 实验任务2：VS平台编写视觉应用软件
将 HALCON 平台完成的视觉检测算法导出为 C++ 代码，在 Visual Studio 2022 中构建完整的视觉应用软件。

**主要流程：**

1. **导出 HALCON 代码**
   - 确认 HALCON 运行效果无误后，导出为 C++ 代码
   - 重点关注导出的 `action()` 函数，所有处理逻辑均在此函数内执行

2. **VS 开发环境配置**
   - 创建 C++ 控制台应用项目
   - 配置 Halcon 头文件路径：项目属性 → C/C++ → 附加包含目录
   - 配置 Halcon 库文件路径：项目属性 → 链接器 → 常规 → 附加库目录
   - 添加链接器依赖项：`halconcpp.lib`（项目属性 → 链接器 → 输入 → 附加依赖项）

3. **代码集成与编译**
   - 将导出的 CPP 文件内容粘贴至项目源文件
   - 重新生成解决方案进行编译，确保无配置错误和语法错误

4. **程序运行与调试**
   - 编译成功后，通过"调试 → 开始执行"运行程序
   - **常见问题**：直接运行会出现闪退（Halcon 导出代码无延时，执行完即退出）
   - **解决方案**：在合适位置添加 `Sleep(2000)` 延时2秒，或使用 `getchar()` 阻塞等待


## 学习目标
- 掌握 MVTec HALCON 开发环境的使用方法
- 理解 Blob 分析在工业视觉质检中的完整流程（预处理→分割→形态学→特征提取→缺陷判定）
- 熟悉图像处理核心算子的功能与使用方法
- 掌握 HALCON 代码导出及 Visual Studio C++ 集成开发流程
- 具备独立完成从算法开发到应用软件交付的工程实践能力
