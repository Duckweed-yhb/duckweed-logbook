# 仿生非轮式越障爬行机器人竞速赛项目 README
## 项目简介
本项目属于**工程训练（制造工艺实习）综合实训核心任务**，3～4人组成小组自主完成一台**仿生非轮式越障爬行机器人**的设计、加工、装配、电控调试、步态编程，并参与赛道竞速竞赛与现场答辩。

赛事全面禁止轮式、履带式行走机构，仅允许**四足、六足、蛇形蠕动、连杆机构**四类无轮仿生结构参赛。支持**全自动模式、遥控模式**两种参赛方式。全自动模式优先级更高，全程无人工干预；遥控模式竞速原始成绩统一按照70%折算。机器人核心硬件优先选用课程统一配发物料；所有非标结构件、传动构件必须由学生自主设计加工，严禁直接使用成品机械套件。

课程无纸质实训报告，项目最终考核要求提交全套工程图纸并完成PPT现场答辩。完整工程链路：方案构思→三维建模→零件数字化加工→机械预装→电控接线→步态调试→赛道竞速→项目答辩。

## 一、赛道标准化参数（以现场实物为准）
赛道总长 **4m**，一体式实训台；仅起点、终点设置红色标线，赛道两侧无边界标识。机器人任意部位冲出、掉落赛道将立即终止本轮比赛。赛道分为三段连续障碍：
1. **第一段｜组合式坡度越障区**
    40°爬坡+45°下坡连续坡道，考核重心控制、步态调节、陡坡稳定通行能力；全自动模式机器人必须成功翻越45°下坡段，本轮成绩才判定为有效全自动成绩。
2. **第二段｜狭窄矮洞隧洞区（狗洞）**
    限制外形尺寸，考验整机尺寸约束、自适应步态调整。隧洞内部通行尺寸：长310mm，宽310mm，高度250mm。
3. **第三段｜弧形沟壑越障区**
    下凹弧形沟槽结构，检验曲面贴合、间隙跨越、动态步态自适应能力。

> 赛道实物存在合理加工公差，所有设计以现场实物赛道为准。

## 二、机器人硬性约束与禁令
1. 整机最大外形尺寸：长度≤300mm，宽度≤300mm，高度≤250mm。
2. 严禁车轮、滚轮、履带、齿轮轮式一切轮类移动机构。
3. 所有非标结构件、机身、传动零件禁止成品套件，必须自主设计加工。
4. 关键受力构件禁止使用纸板、泡沫等非加工类软性材料。
5. 主控硬件优先使用课程标配：**ESP32-S3、MG90S金属舵机、MG4010 RS485电机**。

## 三、参赛控制模式（选定后全程不可更改）
### 1. 全自动模式（推荐，排名优先级最高）
全程无人工干预；从起点自主运行，成功翻越45°下坡段，方可认定为有效全自动成绩。
> 违规：人工触碰、场外遥控、无线干预 → 本轮竞赛成绩清零。

### 2. 遥控模式
竞速原始得分 ×0.7折算计入总分；遥控器、通信模块全部为自备硬件，课程不予报销。
> 违规：手部直接触碰机器人本体、物理辅助行进 → 本轮竞赛成绩清零。

> 参赛机会：每组拥有两轮正式竞速机会，两次比赛不允许切换控制模式，取两次最优成绩作为竞技得分。

## 四、竞速计时与终止判定规则
1. 单轮限时 **180s（3分钟）**，裁判口令下达同步计时；提前启动机器人第一次警告，第二次本轮成绩作废。
2. 机器人最前端完全越过终点红色标线，判定完成全程，停止计时。
3. 触发以下任意条件，本轮比赛立即终止，记录当前有效行进距离：
    - 机器人冲出、掉落赛道；
    - 原地卡顿静止无法前进持续超过20s；
    - 机械结构脱落、卡死无法自主行进；
    - 出现各类模式对应的人工干预违规行为。

## 五、可选仿生结构方案对比
1. **四足机器人**
成熟开源方案多，调试资料丰富；自由度适中，开发门槛适中。
2. **六足机器人**
三角静态步态，稳定性强；凹凸障碍越障性能优秀，适合复杂赛道。
3. **蛇形蠕动机器人**
狭小隧洞通过优势明显；缺点：爬坡性能偏弱，步态串联结构加固要求高。
4. **连杆机构机器人（切比雪夫连杆）**
纯机械联动，所需驱动电机数量少；电控逻辑简单，直线推进稳定。

> 本小组选定**标准四足爬行机器人**作为最终参赛方案。

## 七、7次课程任务与验收标准（每次4课时）
> 统一验收时间：每次课程结束前15分钟

### 第1次课｜项目导入与团队组建
**任务**
1. 完整学习竞赛规则、赛道参数、四种仿生机器人方案；
2. 完成3～4人组队，明确分工：结构/电控/软件/答辩；
3. 领取标配硬件物料并核对清单；如需拓展硬件提交书面申请。
**验收标准**
小组名单签字确认；全体成员熟悉核心竞赛禁令；物料清点核对无误。

### 第2次课｜方案设计与三维建模
**任务**
1. 选定仿生机构方案，并书面说明选型理由；
2. 完成整机三维建模，严格校核外形尺寸≤300×300×250mm；
3. 规划舵机/电机布局、供电方案、基础步态逻辑；
4. 输出零件加工尺寸图纸、电气接线原理图初稿。
**验收标准**
整机3D主体模型完成；步态方案逻辑清晰；工程图纸初稿输出。

### 第3次课｜机构零件加工
**任务**
1. 结构件3D打印、亚克力激光切割下料；
2. 攻丝、去毛刺、尺寸测量，与三维模型比对误差；
3. 机械零件预装配，检验装配间隙与干涉；
4. 完成电控接线前期准备。
**验收标准**
全部结构件加工完成；预装无运动干涉；电气线路预接线通电测试正常。

### 第4次课｜整机装配与基础步态调试
**任务**
1. 机械结构完整装配紧固；
2. 完成全部电控接线、舵机机械零点校准；
3. 编写基础步态程序，测试直行、转向动作。
**验收标准**
整机装配完成无松动卡滞；舵机角度响应正常；机器人能够稳定直行与转向。

### 第5次课｜越障专项步态调试
**任务**
1. 分段测试爬坡、下坡、隧洞通行性能；
2. 持续优化步态时序、机身姿态控制参数；
3. 搭建全自动感知-决策-执行程序框架。
**验收标准**
机器人可稳定通过至少一类赛道障碍；步态切换流畅；全自动控制程序框架完成。

### 第6次课｜全赛道模拟测试
**任务**
1. 在模拟赛道多次完整试运行；
2. 记录卡点故障，迭代优化机械结构与控制程序；
3. 确定两轮正式竞赛策略；启动答辩PPT初稿制作。
**验收标准**
完成多次完整赛道模拟；长时间连续运行无致命故障；答辩PPT初稿完成。

### 第7次课｜仿生越障机器人竞赛答辩
**任务**
1. 开展两轮正式竞速，裁判判定控制模式、完赛状态，取最优一轮成绩；
2. 竞技得分 = 基础行进得分(40分)+竞速效率得分(60分)；
3. 小组依次PPT答辩，汇报主线：分工→方案设计→零件加工→越障调试→创新亮点→成本分析→迭代改进；
4. 提交全套工程图纸（结构尺寸图+硬件接线图+电气原理图）；
5. 评委多维综合打分，汇总全部队伍排名，公布获奖团队。

**验收标准**
1. 两轮竞速完整参与；
2. PPT答辩内容完整、逻辑清晰，可正常实物演示；
3. 全套工程图纸规范标注、与实物匹配；
4. 竞赛结束后全部硬件物料拆解、清点回收，交还指导教师。

> 验收方式：现场竞速 + PPT答辩演示 + 图纸评审 + 物料回收

## 八、课程综合评分体系（五大维度）
总成绩由五大维度构成：**工程素养、工程技能、工程综合、工程认知、工程创新**
1. **工程素养（考勤 + 物料回收）**
    - 考勤：满分100，缺课单次扣10分；迟到/早退单次扣3分，扣至0为止。
    - 物料回收：满分100，每缺失一件物料扣10分，扣至0为止。
2. **工程技能（项目节点提交）**
    每节课节点资料按时提交满分100；延迟提交50分，逾期不提交0分。
3. **工程综合（竞速对抗成绩，满分100分）**
    - 基础行进得分（40分）
      跑完全程得40分；未完成按比例折算：
      `基础得分 = 40 × (实际行进距离 ÷ 赛道总长4m)`
      遥控模式基础得分先计算原始值再×0.7。
    - 竞速效率得分（60分）四档排名机制
      档位划分：
      - 第一档（排名前25%）：60分
      - 第二档（排名25%～50%）：57分
      - 第三档（排名50%～75%）：48分
      - 第四档（排名后25%）：42分
    > 排名优先级规则（从上至下依次判定）
    > ① 全自动模式整体优先于全部遥控队伍
    > ② 同一模式下，完赛队伍优先于未完赛队伍
    > ③ 同是完赛队伍：按完成耗时从小到大排序
    > ④ 同是未完赛队伍：按行进距离从大到小排序；距离相同按耗时升序。
4. **工程认知（项目答辩）**
    多位评审老师独立打分，取平均分；考核团队分工、设计思路、加工工艺、故障复盘、实物展示。
5. **工程创新（专利三性评价）**
    根据答辩展示的结构创新、控制方案创新、步态算法创新综合打分。

## 九、安全操作规程
1. 电烙铁焊接谨防烫伤；3D打印机、激光切割机必须经培训许可后方可上机。
2. 舵机、电机通电调试，禁止手指伸入关节活动区域，防止夹伤。
3. 锂电池仅使用原装充电器充电，远离易燃物，禁止私自改装充电回路。
4. 设备出现异响、异常发热、冒烟，立即断电停机并第一时间报告指导教师。
