## 📌 本学期的整理与使用约定

1. **只放个人产出**；公共资料一律在 `01-学业/公共/11.2028春/`。
2. 一门课一个目录，命名为 `NN.课程名`，**序号仅用于排序**；本学期目录已连续 `1`–`3`。
3. 目录名中的括号一律用**英文半角 `()`**；课程 README 的课程代码 / 学分 / 学时 / 考核方式已按培养方案填好。
