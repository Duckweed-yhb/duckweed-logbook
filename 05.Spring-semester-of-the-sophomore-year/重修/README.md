## 🛠️ 通用说明
- 各课程的 LaTeX 文档均使用 **XeLaTeX** 编译，入口文件一般为 `main.tex`、`1.main.tex` 或 `1.homework.tex`；
- 笔记与作业多为「LaTeX 源码 + 已编译 PDF」，可直接查看 PDF，或重新编译源码生成最新版本。

## 💡 学习建议
- 优先查看各课程 README 中的「章节内容」与「使用建议」；
- 建议「课堂笔记（公式/考点）+ 课后作业（题型/步骤）+ 实验报告（实践）」三线并进，配套复习效果最佳。
