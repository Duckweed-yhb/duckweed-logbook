\chapter{半导体存储电路}
\section{时序逻辑基础与触发器}
\subsection{时序电路基本概念}
\subsubsection{组合电路与时序电路区分}
\begin{itemize}
    \item 组合逻辑电路：仅由门电路构成，无记忆，无反馈，输出仅由当前输入决定；
    \item 时序逻辑电路：包含\textbf{存储单元（触发器）+ 组合逻辑 + 反馈回路}
    \begin{enumerate}
        \item 存储单元保存电路当前状态；
        \item 组合逻辑接收输入，当前状态，计算新状态与输出；
        \item 新状态送入存储单元，等待时钟更新；
        \item 输出由输入+当前状态共同决定。
    \end{enumerate}
\end{itemize}
\noindent 易错提示：两级反相器首尾反馈构成简单存储单元，利用传输延迟实现记忆，属于最基础时序单元。

\subsection{SR锁存器（基本存储单元）}
\subsubsection{或非门构成基本SR锁存器}
电路由两个或非门交叉反馈组成，输入低电平有效$S_D',R_D'$，输出$Q,Q'$；
\begin{itemize}
    \item $S_D'=0,R_D'=1$：置1，$Q=1,Q'=0$；
    \item $S_D'=1,R_D'=0$：置0，$Q=0,Q'=1$；
    \item $S_D'=1,R_D'=1$：保持原有状态；
    \item $S_D'=0,R_D'=0$：不定态，禁止同时为0。
\end{itemize}

\subsubsection{与非门构成SR锁存器}
输入高电平有效$S,R$，逻辑符号S、R输入端无小圆圈；约束条件$SR=0$，禁止$S=R=1$。

\subsection{触发器结构演化脉络（背诵框架）}
无记忆门电路串联 $\rightarrow$ 基本RS锁存器（无同步时钟）
$\rightarrow$ 同步电平触发器（CLK电平控制，空翻缺陷）
$\rightarrow$ 主从式脉冲触发器（解决空翻，仍有SR约束）
$\rightarrow$ 主从JK脉冲触发器（消除不定态，仍存在一次翻转问题）
$\rightarrow$ 边沿触发器（仅时钟边沿采样输入，抗干扰最强）

\subsection{电平触发触发器}
\subsubsection{同步RS电平触发器电路与真值表}
由4个与非门构成：$G_3,G_4$为时钟控制门，$G_1,G_2$构成基础SR锁存器；CLK高电平有效。
\[
\begin{aligned}
&CLK=0:\quad S,R\text{封锁，}Q^*=Q \quad (\text{保持})\\
&CLK=1:\quad
\begin{cases}
S=0,R=0 & Q^*=Q \quad \text{保持}\\
S=1,R=0 & Q^*=1 \quad \text{置1}\\
S=0,R=1 & Q^*=0 \quad \text{置0}\\
S=1,R=1 & \text{不定态，禁止}
\end{cases}
\end{aligned}
\]

\subsubsection{电平RS触发器核心缺陷：空翻现象}
CLK=1高电平区间内，若S/R多次跳变，输出$Q$会跟随输入多次翻转；
\begin{itemize}
    \item 缺陷1：一个时钟周期输出多次变化，逻辑混乱；
    \item 缺陷2：存在约束条件$SR=0$，不能同时输入1；
\end{itemize}

\subsubsection{电平D锁存器（D触发器，消除SR约束）}
将S端接输入D，R端接D反相，电路由5个与非门构成，CLK高电平透明。
\[
Q^* = D \quad (CLK=1\text{有效})
\]
真值表：
\begin{center}
\setlength{\tabcolsep}{4pt}\small
\begin{tabular}{cc|c}
\toprule
CLK & D & $Q^*$ \\
\midrule
0 & $\times$ & $Q$（保持）\\
1 & 0 & 0 \\
1 & 1 & 1 \\
\bottomrule
\end{tabular}
\end{center}
特点：CLK高电平时输出跟随输入，电平透明；CLK变0瞬间锁存当前D值。

\subsection{脉冲触发触发器}
\subsubsection{主从RS脉冲触发器}
电路由两级电平RS触发器串联：
1. 主触发器：CLK=1期间接收S/R，更新主状态$Q_m$；
2. 从触发器：$\overline{CLK}=1$（CLK下降沿）跟随$Q_m$更新输出$Q$；
工作分两步：
\begin{enumerate}
    \item $CLK=1$：主触发器随S/R变化，从触发器锁存不变；
    \item $CLK$下降沿$1\rightarrow0$：主触发器冻结状态，从触发器同步更新，一个时钟周期输出仅变化一次，解决空翻。
\end{enumerate}
约束条件：仍满足$SR=0$，$S=R=1$出现不定态。

\subsubsection{主从JK脉冲触发器（消除SR不定态）}
将输出$Q,Q'$交叉反馈至S、R输入端，等效$S=JQ',\ R=KQ$，彻底消除$S=R=1$不定态。
\[
Q^* = JQ' + K'Q \quad (\text{下降沿更新})
\]
真值表：
\begin{center}
\setlength{\tabcolsep}{3pt}\small
\begin{tabular}{cc|cc}
\toprule
J & K & $Q^*$ & 功能 \\
\midrule
0 & 0 & $Q$ & 保持 \\
0 & 1 & 0 & 置0 \\
1 & 0 & 1 & 置1 \\
1 & 1 & $Q'$ & 计数翻转 \\
\bottomrule
\end{tabular}
\end{center}

\paragraph{一次翻转问题（主从JK核心缺陷）}
CLK=1高电平期间，主触发器仅能翻转一次；一旦主状态改变，无论J/K后续如何变化，$Q_m$不再复原。干扰信号会造成错误输出，抗干扰能力弱。

\subsubsection{脉冲触发器通用特点}
\begin{itemize}
    \item 输出仅在CLK下降沿更新，单周期仅变化一次，无空翻；
    \item 主触发器在CLK=1期间仍接收输入干扰，存在一次翻转缺陷；
    \item JK无约束条件，主从RS仍需$SR=0$。
\end{itemize}

\subsection{边沿触发器}
核心优势：仅CLK边沿瞬间采样输入，其余时间输入变化完全不影响输出，彻底解决一次翻转，空翻，抗干扰最强。
分类：上升沿触发，下降沿触发。

\subsubsection{CMOS传输型上升沿D边沿触发器}
两级D锁存器串联，时钟反相控制传输门TG1/TG2，TG3/TG4：
\begin{enumerate}
    \item $CLK=0$：主级TG1导通，接收D；从级TG3关断，输出锁存；
    \item $CLK$上升沿$0\rightarrow1$：主级TG1关断锁存D；从级TG3导通，输出更新$Q^*=D$；
    \item $CLK=1$：主级隔离输入，从级保持输出，输入D变化无任何影响。
\end{enumerate}
逻辑符号CLK输入端无小圆圈，代表上升沿触发。

\subsubsection{维持阻塞型D边沿触发器}
内置置1维持线，置0阻塞线，上升沿触发；异步置位$S_D'$，复位$R_D'$低电平优先，不受时钟控制。

\subsubsection{下降沿JK边沿触发器}
逻辑符号CLK端带小圆圈，仅下降沿读取J、K输入，其余时刻J/K干扰完全无效，无一次翻转缺陷，工业最常用。

\subsection{触发器逻辑功能与转换}
\subsubsection{电路结构，逻辑功能，触发方式三者关系}
\begin{itemize}
    \item 逻辑功能与电路结构无固定对应关系
    \item 触发方式由电路结构唯一决定
    \begin{enumerate}
        \item 同步4与非门RS：电平触发，CLK高电平全程响应输入；
        \item 两级串联主从RS/JK：脉冲触发，仅CLK下降沿更新输出；
        \item 双D锁存器CMOS/维持阻塞D：边沿触发，仅上升沿采样；
        \item 带圆圈CLK端JK：下降沿边沿触发。
    \end{enumerate}
\end{itemize}

\subsubsection{四类触发器完整对比}
\paragraph{SR触发器}
特性方程：
\[
\begin{cases}
Q^* = S + R'Q \\
SR = 0 \quad (\text{约束条件，禁止}S=1,R=1)
\end{cases}
\]
功能：置1，置0，保持，无计数功能。

\paragraph{JK触发器（万能触发器，无约束）}
特性方程：
\[
Q^* = JQ' + K'Q
\]
功能全覆盖：保持(J=K=0)，置0(J=0,K=1)，置1(J=1,K=0)，计数翻转(J=K=1)。

\paragraph{T触发器（计数专用）}
特性方程：
\[
Q^* = TQ' + T'Q
\]
真值：$T=0$保持，$T=1$翻转计数。

\paragraph{D触发器（锁存/移位专用）}
特性方程：
\[
Q^* = D
\]
功能：跟随输入，锁存数据，无保持/翻转独立模式。

\subsubsection{触发器相互转换}
\begin{enumerate}
    \item JK $\rightarrow$ D：令$J=D,\ K=D'$；
    \item JK $\rightarrow$ T：令$J=T,\ K=T$；
    \item D $\rightarrow$ JK：$D=JQ'+K'Q$；
    \item D $\rightarrow$ T：$D=T\oplus Q$。
\end{enumerate}

\subsubsection{触发器四种描述方法}
\begin{itemize}
    \item 逻辑符号：符号标记含义
    \begin{itemize}
        \item $\wedge$：边沿触发；$\neg$：主从脉冲触发；
        \item CLK端小圆圈：下降沿/低电平有效；无圆圈：上升沿/高电平有效；
        \item $S_D',R_D'$带非号：异步置1，置0，不受时钟控制。
    \end{itemize}
    \item 特性真值表：罗列全部输入，现态对应的次态；
    \item 特性方程：卡诺图化简得到次态逻辑表达式；
    \item 状态转换图：圆圈代表状态，箭头标注输入条件跳转。
    \item 驱动表：给定现态，目标次态，求所需输入。
\end{itemize}

\subsubsection{波形绘图标准解题步骤}
\begin{enumerate}
    \item 写出触发器次态特性方程，标注异步置0/置1优先级；
    \item 标注电路初始状态，全程优先检查异步置位/复位信号；
    \item 特性方程仅在有效时钟沿/有效电平区间生效，其余时刻保持；
    \item 分类型绘图规则
    \begin{itemize}
        \item 电平锁存器：CLK高电平跟随输入，下降沿锁存；
        \item 主从JK：CLK=1主触发器可变，下降沿定输出，存在一次翻转；
        \item 边沿触发器：仅有效沿读取输入，其余干扰无效。
    \end{itemize}
\end{enumerate}

\subsubsection{波形绘图例题示范}
例：下降沿JK触发器组合电路，输入A、B、初态$Q=0$
推导驱动输入：
\[
J=\overline{A+A\overline{Q}}=\overline{A},\quad K=\overline{B+B\overline{Q}}
\]
代入JK特性方程：
\[
Q^* = \overline{A}\,Q' + B\,Q
\]
分情况化简，根据时钟下降沿分段绘制波形。

\subsection{触发器全章核心小结}
\begin{itemize}
    \item 本质：触发器是1位二进制存储时序单元；
    \item 结构演化：基本锁存器$\rightarrow$电平同步$\rightarrow$主从脉冲$\rightarrow$边沿触发器；
    \item 功能分类：SR（带约束），JK（万能无约束），D（锁存），T（计数）；
    \item 触发方式对比
    \begin{itemize}
        \item 电平触发：CP全程响应，有空翻；
        \item 主从脉冲：下降沿更新，存在一次翻转；
        \item 边沿触发：仅边沿采样，无空翻无一次翻转，抗干扰最优；
    \end{itemize}
    \item 工程选型：集成电路仅D、JK，异步端低电平优先；
    \item 解题工具：特性方程，真值表，状态转换图，驱动表。
\end{itemize}

\subsection{寄存器}
\subsubsection{寄存器基础定义}
寄存器用于存储一组多位二进制代码；多位寄存器由对应数量触发器构成。
\begin{itemize}
    \item 分类：数码寄存器，移位寄存器；
    \item 输入模式：并行输入，串行输入；
    \item 输出模式：并行输出，串行输出；
    \item 典型芯片：74LS75，74LS175。
\end{itemize}

\subsubsection{四位并行数码寄存器}
由4个D触发器构成，统一时钟并行读写，带全局清零端。

\subsubsection{四位右移移位寄存器}
每时钟脉冲右移一位；支持串入，串出，并行输出；串行存入多位数据需要对应时钟周期。

\section{半导体存储电路}
\subsection{存储器总体分类}
读写特性划分
\begin{itemize}
    \item ROM只读存储器：出厂固化，正常仅可读；细分掩模，PROM，EPROM，Flash；
    \item RAM随机读写：随时读写，断电丢失；细分SRAM，DRAM。
\end{itemize}

\subsubsection{SRAM静态随机存储器}
硬件结构：地址译码器，存储矩阵，读写控制，片选，三态端口。
\begin{itemize}
    \item $CS'=1$：芯片未选中，端口高阻；
    \item $CS'=0$：芯片工作，$R/W'=1$读，$R/W'=0$写。
\end{itemize}
静态单元：六管MOS，依靠触发器存数据，无需刷新。

\subsubsection{DRAM动态RAM}
依靠电容存电荷，集成度高，必须定期刷新，自学了解。

\subsubsection{ROM只读存储器}
电路结构：地址输入$\rightarrow$译码$\rightarrow$存储矩阵$\rightarrow$输出缓冲；交叉点有元件记1，无记0。
ROM细分
\begin{enumerate}
    \item 掩模ROM：工厂一次性固化，大批量低成本；
    \item PROM：用户一次性编程，不可改写；
    \item EPROM/Flash：可多次擦写，闪存用于U盘，手机。
\end{enumerate}

\subsubsection{存储器容量扩展}
容量格式：字数$\times$位数；两种扩展
\begin{enumerate}
    \item 位扩展：单片位宽不足，多片数据线并联拓宽位；
    \item 字扩展：单片存储量不足，高位地址译码区分各芯片片选。
\end{enumerate}

\subsubsection{字扩展电路实例}
采用4片$256\times8$位RAM，搭配2线-4线译码器实现$1024\times8$位存储容量。
\begin{itemize}
    \item 低位地址$A_0\sim A_7$全部并联接入四片RAM地址端；
    \item 读写控制信号$R/W'$全局并联；
    \item 高位地址$A_8,A_9$送入2线-4线译码器，译码输出分别接四片片选$CS'$；
    \item 所有芯片8位I/O数据线并联作为总输出端口。
\end{itemize}

\subsubsection{用ROM实现组合逻辑函数}
\paragraph{基本原理}
ROM分为地址译码与阵列，存储矩阵或阵列两部分。将输入变量作为ROM地址输入，每根字线对应一个最小项，数据线输出即为输入变量组合逻辑函数，天然实现多输出逻辑电路。
ROM结构本质：固定与阵列 + 可编程或阵列。

\paragraph{实例1：多输出逻辑函数实现}
给定四输入四输出逻辑表达式：
\[
\begin{cases}
Y_1 = A'BC + A'B'C \\
Y_2 = AB'CD' + BCD' + A'BCD \\
Y_3 = ABCD' + A'BC'D' \\
Y_4 = A'B'CD' + ABCD
\end{cases}
\]
转换为最小项之和形式：
\[
\begin{cases}
Y_1 = \sum m(2,3,6,7) \\
Y_2 = \sum m(6,7,10,14) \\
Y_3 = \sum m(4,14) \\
Y_4 = \sum m(2,15)
\end{cases}
\]
实现方案：选用$16\times4$位ROM，4位输入变量$A,B,C,D$接地址端$A_3,A_2,A_1,A_0$，存储矩阵对应最小项位置打点，四根数据线分别输出$Y_1,Y_2,Y_3,Y_4$。

\paragraph{实例2：ROM实现八段字符显示器}
采用4输入16线地址译码ROM，输入$D,C,B,A$代表4位BCD数字；8位数据线输出对应八段数码管$a,b,c,d,e,f,g,h$；存储矩阵按数字显示字形打点，片选使能$EN'$低电平有效，直接驱动共阴极/共阳极数码管。
