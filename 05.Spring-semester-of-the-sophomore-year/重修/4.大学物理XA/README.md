# 大学物理 XA（课程 README）

## 📚 课程概述
大学物理 XA 是理工科专业的基础课程，本目录整理了两套配套资料：

- **学习笔记**：核心公式与考点汇总，覆盖力学、电磁学、振动与波动三大模块；
- **作业集**：分章节课后作业与完整解题步骤，用于刷题与题型归纳。

## 📁 资料目录结构
```
大学物理XA/
├── 学习笔记/   # 核心公式与考点汇总（LaTeX 笔记）
└── 作业集/     # 课后作业习题集（LaTeX）
```

## 📖 内容章节

### 第一篇 力学
1. 质点运动学
2. 质点动力学
3. 刚体力学基础
4. 流体力学
5. 狭义相对论

### 第二篇 电磁学
6. 电荷与电场
7. 电流与磁场
8. 电磁场与麦克斯韦电磁场方程组

### 第三篇 振动与波动
9. 振动学基础
10. 波动学基础
