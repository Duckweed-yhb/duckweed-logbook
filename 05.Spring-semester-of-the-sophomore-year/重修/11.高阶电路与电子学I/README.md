# 高阶电路与电子学 I（课程 README）

## 📚 课程概述
高阶电路与电子学 I 是电气工程及其自动化专业的核心专业基础课，本目录整理了两个主要模块的完整课堂笔记：

- **模拟电子技术基础**：半导体器件、放大电路、集成运放、反馈、信号运算处理、功率放大、直流电源等；
- **电路理论基础**：电路元件与基本定律、线性直流电路、正弦电流电路、三相电路、动态电路暂态分析等。
