# 电路与电子学 III（课程 README）

## 📚 课程概述
电路与电子学 III 以**电路理论基础**为核心，整理了一套「核心公式与考点汇总」课堂笔记，覆盖直流电路、交流稳态电路、动态电路暂态分析等核心内容，适合课程复习、期末速查与考研基础。

## 📁 资料目录结构
```
电路与电子学III/
├── 课程笔记/       # LaTeX 笔记（1.main.tex + 各章节 tex 文件）
└── 参考资料/
    ├── 电路理论基础.pdf
    └── 电路习题解答.pdf
```

## 📖 章节内容
1. 电路元件与基本定律
2. 线性直流电路
3. 电路定理
4. 正弦电流电路
5. 三相电路
6. 非正弦周期电流电路
7. 频率特性和谐振现象
8. 线性动态电路暂态过程的时域分析
9. 线性动态电路暂态过程的复频域分析
10. 二端口网络
11. 网络图论与网络方程
12. 非线性电阻电路
13. 均匀传输线
