## 📊 成绩构成与考核方式
> 最终成绩 = 学习笔记 50% + 小组实践汇报 50%

### 课堂签到说明
每节课设置签到环节，签到记录疑似不计入课程总分。

### 1. 学习笔记（报告）
针对课程内容，调研相关资料，撰写学习笔记（报告）
1. 字数要求：不少于1500字
2. 提交方式：文档发送至邮箱 `zhouyexin@hit.edu.cn`

### 2. 小组实践汇报
1. 任务要求：选用一款工业软件完成一项完整任务
2. 分组限制：小组人数不超过4人
3. 汇报时长：5分钟左右
4. 展示节点：课程最后一次课进行现场汇报
