# SEIN1005《走进新能源》课程 README
## 📚 课程基础信息
- **课程代码**：SEIN1005
- **课程名称**：走进新能源
- **开课学期**：2026年春季学期

---

## 📊 成绩构成与考核方式
> 最终成绩 = 平时成绩30% + 期中成绩30% + 期末成绩40%

### 1. 平时成绩（30%）
本课程无传统点名，**考勤与平时分全部依托课堂线上小测完成**。
- 每节课课堂发放二维码，扫码进入线上答题；
- 题目难度极低，仅考察当节课基础知识点，无计算、无复杂理论推导；
- 按时完成扫码答题即可获得本次小测满分；
- 缺课未参与随堂小测会扣除对应课时平时分数。

### 2. 期中成绩（30%）
期中考核形式为课程专题报告，无固定限定选题，自主从课程能源相关方向选取主题撰写，文档字数不少于1500字，提交截止时间为4月10日。
可选参考写作主题方向：
1. 化石燃料（石油、天然气和煤炭）的未来发展
    - 二氧化碳排放带来的环境影响
    - “石油峰值”理论与资源约束
    - 化石能源产业转型路径
2. 核能发展分析
    - 核能短期、长期视角下能否作为主流能源解决方案
    - 快中子反应堆增殖原理与产业化发展趋势
    - 核废料处理技术、核电安全管控体系
3. 可再生能源综合分析
    - 风能、地热能、太阳能、可燃冰等各类可再生能源概况
    - 现有储量与潜在可开发资源规模
    - 各类可再生能源技术自身优势与现存短板
4. 可燃冰产业化前景
    - 可燃冰是否具备大规模替代石油的潜力
    - 可燃冰开发面临的机遇与技术、环境挑战
    - 我国可燃冰开采、利用的对策建议
5. 新型储能技术发展研判
    - 电化学储能、新型储能支撑电力可充放电体系的未来走向
6. 新能源前沿开发应用话题
    - 光催化制氢、钍基熔盐堆、超临界二氧化碳发电
    - 钙钛矿新型太阳能电池、大数据驱动新能源智能管理
7. 能源形势与相关政策
    - 碳排放交易、碳中和实施路径
    - 燃煤火力发电结构转型、能源领域多边国际合作
    - 能源治理下服务型政府模式转型
8. 能源与经济协同发展
    - 多元能源市场主体市场化改革思路
    - 新能源产业新型商业运营模式

### 3. 期末成绩（40%）
期末考核为小组PPT汇报形式的期末报告，4人一组完成，汇报主题限定**与新能源应用和开发相关的前沿话题**。
#### 汇报基础要求
1. 时长：15~20分钟，包含现场问答环节
2. 展示时间：第9~10周（4月27日、4月29日、5月6日）
3. 展示顺序：课上待定分组顺序
#### 可选三大类前沿选题
##### （1）前沿技术与关键材料类
1. 钙钛矿太阳能电池
2. 钠离子电池
3. 全固态电池
4. 超临界CO₂发电
5. 光裂解水制氢
6. 绿色甲醇与绿色氨
7. 可持续航空燃料
8. 超热岩地热能
9. 小型模块化反应堆
10. CO₂捕集、利用与封存
##### （2）政策治理与国际竞争类
1. 碳交易与碳税
2. 绿电交易与绿证
3. 欧盟CBAM机制
4. 关键矿产供应链
5. 关税、补贴和产业政策
6. 绿氢认证和碳足迹
7. 核电复兴的政策逻辑
8. 能源转型中煤电地区与传统产业转型
9. 大型能源项目审批的生态约束
##### （3）市场产业与商业模式类
1. 光伏产能过剩与价格战
2. 储能项目盈利模式
3. 虚拟电厂商业模式
4. 家庭光储一体化
5. 电池回收与梯次利用
6. 绿氢项目停留在示范阶段的原因
7. 数据中心绿电采购与PPA重塑市场关系
8. 新能源就业与技能缺口
9. 地缘政治与融资环境

#### PPT报告固定写作结构
1. 封面：报告题目、课程名称、小组全部成员及学号
2. 选题与核心问题：明确本次调研研究的核心问题
3. 背景与现实意义：说明选题前沿价值、研究必要性
4. 基本概念与原理机制
    - 技术类：讲解工作原理、完整技术路线
    - 政策类：讲解制度设计、管控目标、运行机制
    - 市场类：讲解产业链构成、成本结构、盈利逻辑
5. 最新进展与关键数据：必须附带两张标注来源的图表，以数据说明产业现状
6. 典型案例：至少1个真实行业案例，可增加多案例对比分析
7. 当前发展挑战与行业争议点
8. 行业未来趋势与小组自主研判
9. 总结结论
