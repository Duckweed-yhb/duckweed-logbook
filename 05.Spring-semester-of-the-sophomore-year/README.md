## 📌 仓库通用规范
1. 每门课程独立文件夹，内部包含：课程README、笔记、作业、报告、仿真工程、复习资料；
2. LaTeX课程论文/实验报告统一附带源码与导出PDF，文档内标注**仅作学习参考，严禁直接抄袭**红色声明；
3. 仿真类工程（Simulink/PLECS/MATLAB）附带操作说明与调试记录；
4. 所有复习资料按「随堂讲义→课后习题→期末考点」分层整理，便于考前快速复习。

## 💡 仓库使用说明
1. 电气专业核心课（电磁场、自控、信号、高阶电路、工业软件、新能源等）包含可复用仿真模型与专业写作素材，可直接用于科创、竞赛报告背景参考；
2. 思政通识课（形势与政策、毛概、走进新能源）提供规范课程论文模板与写作思路；
3. 所有学习资料均为个人课堂整理记录，仅供个人学习复习使用，请勿直接照搬提交课程作业。
