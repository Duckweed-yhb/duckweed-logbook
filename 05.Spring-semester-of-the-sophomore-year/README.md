## 📌 本学期的整理与使用约定

1. **只放个人产出**；公共资料（课件 / 电子课本 / 习题册）一律在 `01-学业/公共/5.2026春/`。
2. 一门课一个目录，命名为 `NN.课程名`，**序号仅用于排序**；本学期目录已连续 `1`–`14`。
3. LaTeX 课程论文 / 实验报告附源码与导出的 PDF；仿真类工程（Simulink / PLECS / MATLAB）附操作说明与调试记录。
4. 复习资料按「随堂讲义 → 课后习题 → 期末考点」分层整理，便于考前快速复习。
5. 各课程 README 里标 `（待补）` 的字段只有本人能填。

## 💡 使用说明

所有学习资料均为个人课堂整理记录，仅供个人学习复习使用，请勿直接照搬提交课程作业。
