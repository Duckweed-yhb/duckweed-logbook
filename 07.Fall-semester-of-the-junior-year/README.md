## 📌 本学期的整理与使用约定

1. **只放个人产出**；公共资料一律在 `01-学业/公共/10.2027秋/`。
2. 一门课一个目录，命名为 `NN.课程名`，**序号仅用于排序**；本学期目录已连续 `1`–`6`。
3. 目录名中的括号一律用**英文半角 `()`**，不用全角 `（）`（`DSP的原理与应用`、`AI+电力电子技术` 里的 `+` 保留）。
4. 课程 README 里的课程代码 / 学分 / 学时 / 考核方式已按培养方案填好；标 `（待补）` 的
   （修读状态 / 主讲教师 / 教材 / 成绩构成）只有本人能填。
