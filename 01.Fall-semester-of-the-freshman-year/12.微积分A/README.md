## 🔁 维护方式（2026-11-06 更新）

1. **改内容 → 改 `课程笔记/latex/*.tex`**（唯一正文源）。
2. **编译出 PDF**：
   ```powershell
   powershell -ExecutionPolicy Bypass -File "课程笔记\build.ps1"
   ```
   脚本做两遍 `xelatex`（补目录与交叉引用），把 `1.main.pdf` 复制成 `pdf\微积分A课程笔记.pdf`；`.aux/.log/.toc` 全留在 `pdf\.build\`，不污染 `pdf\`。
   > 输出目录是编译参数（`-output-directory`），无法写进 `.tex` 内部；因此统一走 `build.ps1`。若用 VS Code LaTeX Workshop，可设 `"latex-workshop.latex.outDir": "%DIR%/../pdf"`。
3. **再导出 md → 直接写到知识库**（原仓库不再建 `markdown/`）：
   ```bash
   pandoc -f latex -t markdown --wrap=none 课程笔记/latex/5.导数与微分.tex \
          -o "<知识库>/01-学业/课程笔记/01.Fall-semester-of-the-freshman-year/12.微积分A/课程笔记/3.导数与微分.md"
   ```
   导出的 md 开头会自动带「本文件由 … 自动导出，不要直接编辑」的说明头（导出后手工补上，或按本文件模板加）。
4. **`拓展/`** 已并入 `latex/10.拓展.tex`：先改知识库里的 `拓展.md`，再同步 `latex/10.拓展.tex`（两者当前内容一致，md 便于阅读、tex 供编译）。
5. **章节编号偏移**：`latex/` 里 `1.main.tex`、`2.cover.tex` 占前两号 → 章节 tex 是 **3–9**；知识库里的 md 是按章序命名的 **1–7**。同章不同号，**按中文标题对，不要按数字对**（例：`1.函数.md` = `latex/3.函数.tex`）。
