## ✍️ 有实质内容的 3 门

3 门课统一采用同一套结构：

```
课程笔记/
├── build.ps1          两遍 xelatex，成品复制到 pdf/
├── latex/             0.样式.tex + 1.main.tex + 2.cover.tex + 章节正文
└── pdf/
    ├── <课程名>课程笔记.pdf
    └── .build/         .aux/.log/.toc 等中间文件
```
