1. **识别出 3 个孤儿 tex**：`3.力学` / `4.电磁学` / `5.振动与波动` 是旧版的"三大块合订本"，**两个主文档都没有 `\input` 它们** → 移入 `_旧版合订本/`（不删，备查）。

3. **摘要类 md 提级**：`公式大全` + `物理概念 定理 定律` + `期末/期末考试题目大全` → 合并成 `复习/复习.md`；`拓展.md` → `拓展/拓展.md`；`题库/1.力学` → `习题/1.力学.md`。
