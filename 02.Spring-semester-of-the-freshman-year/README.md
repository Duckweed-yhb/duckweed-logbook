## 📌 本学期的整理与使用约定

1. **只放个人产出**；公共资料（课件 / 电子课本 / 习题册）一律在 `01-学业/公共/2.2025春/`。
2. 一门课一个目录，命名为 `NN.课程名`，**序号仅用于排序**（去掉序号即课名）；本学期目录已连续 `1`–`14`。
3. LaTeX 文档统一采用「`1.main.tex` 总入口 + `2.cover.tex` 封面 + 章节文件」的组织方式；
   **编译产物（`.aux`/`.log`/`.out`/`.synctex.gz` 等）不进版本库**（已由 `.gitignore` 覆盖），但**编译好的 PDF 保留**。
4. 各课程 README 里标 `（待补）` 的字段（课程代码 / 学分 / 学时 / 主讲教师 / 考核方式 / 教材）只有本人能填。
